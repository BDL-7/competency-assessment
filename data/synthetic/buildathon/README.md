# Synthetic buildathon data

- `users.csv` contains 70 fictional people with varied example roles.
- `generate_users.py` recreates the local CSV; no HIR/MIST data is used.
- Roles are illustrative labels, not approved access assignments or lab policy.
- The CSV is Git-ignored and is not loaded by the app.
- `edge-cases.json` lists fictional missing, incomplete, conflicting, and projected-data scenarios.
- The existing one-record demo remains separate; service identities are not included here.
