# Documentation

The public repository contains documentation manifests and repository policy.
Current project-plan binaries and controlled laboratory sources are kept out of
public Git and must be obtained through an approved internal channel.

- `PRODUCT.md` records the scope-locked prototype boundary and exclusions.
- `SOURCE_AUTHORITY.md` defines the governing order, conflicts, and stale-source
  behavior.
- `TERMINOLOGY.md` defines current implementation terms and legacy boundaries.
- `ARCHITECTURE.md` defines the approved modular Flask and Azure boundaries.
- `DOMAIN_MODEL.md` records the conceptual entities and invariants.
- `WORKFLOW.md` records the canonical states, transitions, and open rules.
- `AUTHORIZATION.md` records role, scope, action, and support boundaries.
- `DATA_MIGRATION.md` records staging, lineage, exception, and reconciliation
  controls without authorizing migration execution.
- `AI_BOUNDARY.md` defines the separate read-only assistant and prohibited
  capabilities.
- `TESTING.md` defines required application, authorization, accessibility,
  migration, and AI validation.
- `DEVELOPMENT.md` records the future repository and issue-first workflow.
- `OPERATIONS.md` records environment intent and production approval gates.
- `project/README.md` describes the governing project documents.
- `project/ca-architecture-one-pager.md` is the public-safe Azure AI platform
  support review summary.
- `architecture-decisions/` records public-safe architecture decisions.
- `controlled-sources/README.md` describes controlled domain inputs.
- `SOURCE_MANIFEST.md` records authority, availability, and required metadata.
