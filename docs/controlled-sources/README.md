# Controlled sources

Controlled competency forms and laboratory guidance are not published here.
An authorized project environment must provide approved, versioned copies with:

- document owner;
- version and effective date;
- approval status;
- cryptographic hash;
- retirement or supersession status;
- permitted use and distribution classification.

The knowledge assistant must operate only on the approved corpus and must cite
the governing source. It cannot assess evidence, approve competency, sign, or
change official records.
