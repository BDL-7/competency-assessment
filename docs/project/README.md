# Governing project documents

The current Project Plan, Architecture and Implementation Guide, and Business
Value document are not published in this public repository.

Authorized copies must be checked against `../SOURCE_MANIFEST.md` before use.
The Project Plan governs scope and workflow. The Architecture Guide governs
technical implementation. A presentation may record a newer stakeholder
decision, but it must not silently override either governing document.

The public-safe
[`ca-architecture-one-pager.md`](ca-architecture-one-pager.md) gives the Azure
AI platform support team a concise review entry point. It summarizes the
proposed services, support boundary, workflow, AI controls, and open platform
questions without publishing the controlled governing documents.
