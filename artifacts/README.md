# Output destinations and release history

This public directory contains guidance and historical manifests, not a complete
collection of the deliverables they describe.

- `generated/`: ignored destination for newly built outputs.
- `renders/`: ignored destination for visual QA images.
- [archive/](archive/README.md): dated historical release/concept manifests and
  tracked instructions. Companion binaries or HTML packages may be held outside
  public Git; a manifest does not prove a local copy is present.

Outputs and archives are supporting evidence, not independent product, policy
or architecture authority. Use approved sources/builders rather than editing
renders directly. Release approval is still required before sharing outputs.

Completed task contracts and one-time tooling evidence have a separate home in
the [documentary archive](../docs/archive/README.md).
