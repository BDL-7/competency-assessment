# Generated and Review Artifacts

This directory contains generated deliverables, visual QA renders, and dated historical archives. These files are retained for traceability but are not independent sources of policy or architecture authority.

- `generated/` is the destination for newly built deliverables.
- `renders/` contains current page and slide images used for visual verification.
- `archive/` contains superseded plans, presentation concepts, and retained historical release packages.

Rebuild authoritative deliverables from the corresponding source documents or scripts; do not edit rendered outputs directly.
